# 后台操作日志

入口：系统管理 → 操作日志（`/admin/logs`）。沿用现有权限：所有后台管理员均可查询，账号维护仍仅超级管理员可用。查询接口为 `GET /api/admin/operation-logs`、`/options` 和 `/{id}`，没有修改或删除接口。

记录后台登录/退出、资料新增/编辑/删除、发布/下架、账号启停及密码维护、文件上传、询单状态、通知重试及各项配置保存。自动采集执行账号与姓名快照、时间、模块、动作、目标、接口状态、耗时、连接来源和服务端生成的追踪编号。操作失败也会记录，历史记录不会随账号改名或删除而变化。

只读取白名单中的名称、编号和状态元数据，不保存密码、授权码、请求/响应正文、Cookie、Token、客户留言或文件内容。普通页面浏览、数据刷新、访客询单和访问统计事件不计入人员操作日志。日志中的通知成功表示提交接口成功，实际投递结果仍在邮件通知中查看。

数据库新增 `admin_operation_logs` 表。首次升级对已有数据库执行 `database/migrations/2026-10-30-operation-logs.sql`，然后部署新后端和前端。默认 Spring SQL 初始化和 `npm run db:build` 安装包均已包含此表；若 `TZME_SQL_INIT_MODE=never`，需单独执行该迁移。迁移只新增表和索引，不修改旧资料或账号。

日志从此版本启用后开始产生，无法补录此前的操作。日期筛选和显示采用浏览器时区，数据库保存时间点。来源地址使用后端连接地址，不直接信任任意转发请求头；代理环境需在基础设施层正确配置可信代理。日志读取分页、按时间/操作人/模块建立索引，不自动清空。

预览链接的后台继续使用独立演示数据；预览操作不进入真实日志。数据库导出工具按实际表自动备份本表，导出文件继续保存在 Git 忽略的快照目录。
