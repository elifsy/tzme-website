# 全球业务地图

首页、关于我们及后台实时预览共用 `GlobalReachSection`，采用方案 A「蓝灰航线」。左侧保留后台配置的标题、描述、数据和跳转，右侧为完整平面点阵地图。标题和描述沿用全站 `.hc-h2`、`.hc-p` 字体规则。手机端上下排列，文字与点位、航线保持间距，前台不显示点位数量说明。

地图使用 `WorldReachMap` 的 `blue-gray` 外观，后台点位编辑器维持原外观与编辑功能。天津出发的航线、轮船、点位提示、点击埋点和自定义图片模式均使用原有配置。离开视口或隐藏页面时暂停动效，并遵循系统减少动态效果设置。后台预览不产生埋点。

当前地图仅使用本地点阵 SVG 和 CMS 中的坐标、名称，无需三维地球渲染器或地球纹理。新增、移动和删除点位继续由后台维护，无需数据库迁移。
