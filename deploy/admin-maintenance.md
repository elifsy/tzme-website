# 当前官网后台维护路径

合作伙伴入口为“企业资料 → 合作伙伴”：维护原站 24 项标志、名称、顺序和显示状态，首页及关于我们复用；手机端默认两行，可展开全部。首页配置导航中也提供入口。

访问分析已覆盖当前产品类型多选、3D 交互、资质详情、英文官网跳转、附件点击及合作伙伴展开，口径见 [埋点维护](analytics-events.md)。

后台入口为 `/admin`。普通管理员和超级管理员使用相同的内容维护功能，账号管理仅对超级管理员开放。

| 需要调整的内容 | 后台入口 | 展示位置与填写规则 |
| --- | --- | --- |
| 产品介绍、产品类型、行业关联、图片与设备布局 | 内容管理 → 产品资料 | 产品中心与详情；产品类型与所属行业分别填写，行业可多选 |
| 行业名称、图标与顺序 | 内容管理 → 行业分类 | 首页行业入口与产品中心；产品中心按已有已发布产品展示行业 |
| 新闻、展会与产品手册资讯 | 内容管理 → 新闻资讯 | 公司新闻、展会活动、下载中心为固定类型；中文标题、封面与发布日期必填，可继续创建自定义类别。选择下载中心后上传资料附件 |
| 首页推荐方案及行业按钮 | 页面展示 → 首页方案文案 | 先在产品资料中选择最多 5 个首页推荐，再维护方案文案和顺序；未填写的方案文案采用对应行业或产品资料 |
| 企业介绍与统计数据 | 企业资料 → 企业介绍 | 分别维护首页简介和关于我们，预览入口随当前页面切换 |
| 基地照片、总部及下属企业信息 | 企业资料 → 企业与联系方式 | 在总部、下属企业页签维护，照片与对应地址放在同一资料项中 |
| 页脚联系方式、社交链接 | 企业资料 → 企业与联系方式 | 联系信息与联系页共用；社交链接单独维护并在当前页脚背景中检查效果 |
| 制造与质量流程 | 页面展示 → 制造与质量流程 | 首页、关于我们与设备详情复用相应资料 |
| 证书图片或 PDF | 企业资料 → 资质与质量体系 | 关于我们资质卡片与详情；保持文件完整清晰，核对名称、编号和有效期 |
| 全球地图、城市点位及统计 | 页面展示 → 全球业务 | 首页与关于我们共用资料；预览确认中国出发点、其他城市及航线显示 |
| 咨询表单、必填项及附件规则 | 客户咨询 → 咨询表单与附件 | 首页和联系我们可分别设置展示位置；预览不提交咨询或上传附件 |
| 客户留言与邮件通知 | 客户咨询 → 客户咨询 / 邮件通知 | 留言跟进与发件、收件配置分别维护 |
| 搜索标题、摘要、公开问答、ICP备案号 | 页面展示 → 搜索与 AI 展示 | 产品和新闻默认沿用已发布资料，站点地图自动更新；平台验证和提交仍在对应平台完成 |
| 暂未展示的项目资料 | 保留功能 → 项目资料 | 原资料、编辑和首页选择保留；保存和发布状态不会恢复官网项目入口 |

工作台提供新闻、搜索维护与必填资料检查的快捷入口。产品和新闻列表可筛选待完善记录；新闻另有类别筛选、列表顺序与发布日期。只有已发布的记录提供公开页面链接；草稿、新建记录在编辑器内预览。

新闻实时预览与官网详情共用展示组件，桌面采用标题与封面并列布局，手机使用实际移动视口。预览中可以检查未保存内容，公开页面链接始终指向已保存资料；产品详情继续复用实际设备展示组件。

中文类别名称相同时归为同类。修改单篇文章的名称只改变该文章的归属；清空类别后保存会同时清除该篇历史类别标识，避免再次出现英文分组干扰。类别名称首尾空格在保存时清理。

公司新闻、展会活动、下载中心三个类型不依赖文章数量，清空或删除文章后仍显示在后台与官网分类中，不提供删除类型的操作。已有的自定义类别和文章归属保持不变。

下载中心编辑器新增“资料附件”区，可多选或拖拽上传 PDF、Word、Excel、PPT、ZIP、DWG / DXF、JPG / PNG，每篇最多 10 个，单个文件不超过 20 MB。上传完成后保存文章，官网详情页会出现资料下载列表；编辑器预览也展示文件名与大小。移除附件需要保存才生效，切换到其他类型不会自动丢弃已选附件。正文中原有的下载链接保留。

后端启动时自动执行 `28-article-attachments.sql` 创建附件表；现有数据库也可单独执行 `database/migrations/2026-10-28-article-attachments.sql`。该脚本可重复执行，不改写已有文章。附件文件保存在现有上传目录的 `articles/` 子目录，数据库表与此目录需要一起备份。未保存或草稿文章的附件仅登录管理员可下载，文章下架、删除或移除附件后，公开下载入口停止访问。普通管理员可上传附件，仍使用已有登录和 CSRF 校验。

首页配置导航按当前官网顺序组织，并单独说明固定 Banner、独立新闻页及暂未展示的项目功能。固定视觉与动效沿用当前版本，此次整理不自动改写已有资料或增加账号权限。
