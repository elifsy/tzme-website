# www.tzme.net 国内 SEO / GEO 上线说明

本次建设以官网真实公开资料为基础，重点覆盖搜索可读取内容、统一企业信息、产品资料、制造服务问答和公开资料索引。原有浅色视觉、三维场景、咨询流程与管理权限继续沿用。

## 发布文件和服务

1. 在项目根目录执行 `npm run build`，构建 `dist/`。
2. 在 `server` 目录执行 `mvn package`，更新 Java 服务。
3. 将 `dist/` 内容放入 Nginx 的站点目录，设置 Java 环境变量 `TZME_FRONTEND_DIR` 为同一目录的绝对路径，例如 `/var/www/tzme`。
4. 使用本目录的 `nginx.conf` 更新路由，执行 `nginx -t` 后加载配置。首页与其他 HTML 页面由 Java 根据数据库生成，Nginx 提供 `/assets/` 等静态资源并代理 API。
5. 为 `www.tzme.net` 配置 HTTPS；裸域 `tzme.net` 统一跳转到 `https://www.tzme.net`。生产后台设置 `TZME_SESSION_COOKIE_SECURE=true`，数据库与上传目录继续按原部署方式备份。

Java 自动执行 `26-seo-settings.sql` 初始化尚不存在的搜索配置，重复启动保留后台修改。已有产品、资讯、企业介绍、联系方式和管理员账号保持原有资料。日常资料更新由数据库直接反映到新页面请求，修改资料后无需为搜索内容另做一次静态导出。

## 后台填写顺序

入口：**页面展示 → 搜索与 AI 展示**，地址 `/admin/seo`。普通管理员和超级管理员均可使用。

1. “网站基础资料”：确认正式域名为 `https://www.tzme.net`，简称与介绍符合公司实际信息。真实 ICP 备案完成后填写备案号；空值时页脚不显示号码。
2. “页面标题与摘要”：先看首页、关于我们、产品中心、资讯和联系我们；产品、行业及资讯默认沿用已发布资料，可按需要单独填写。修改标题应准确说明页面主题，摘要写实际服务内容和适用场景。
3. “制造服务问答”：填写客户常问且公司能够确认的内容。当前默认突出按客户图纸制造、焊接加工、装配试装、质量检验及交付，不添加设计能力、具体交期或性能承诺。回答可以分段，问答内容在网页上直接展示。
4. “搜索平台验证”：在对应平台添加域名，使用标签验证时，将 `content` 的值填入对应输入框，保存后再到平台完成验证。

公司名称采用现有官网名称；电话、邮箱和地址沿用“企业与联系方式”；制造流程、基地和资质资料沿用相应后台模块。更新证书时同时核对文件、有效期和适用范围。

## 公开文件和收录入口

| 地址 | 用途 |
| --- | --- |
| `https://www.tzme.net/robots.txt` | 公共页面抓取规则，保护后台及内部目录，允许公开图片资源 |
| `https://www.tzme.net/sitemap.xml` | 随已发布内容更新的 XML 站点地图 |
| `https://www.tzme.net/site-map` | 人和搜索程序都可访问的行业、产品和企业资料目录 |
| `https://www.tzme.net/llms.txt` | 中文公开资料导航，链接到实际的官网页面 |

在百度搜索资源平台及其他站长平台验证域名后，根据平台实际开放的提交入口提交站点地图或公开链接。网站不会代替平台完成账号归属验证，也不会在缺少授权凭据时自动提交链接。

`llms.txt` 是公开资料导航的补充。平台是否读取、何时建立索引及是否引用官网资料，由相应平台决定。

## 发布后的核对

- 查看首页和一个产品详情的网页源码，应直接存在中文标题、设备说明、链接和结构化资料；关闭 JavaScript 仍可阅读这些内容。
- 比较 `www.tzme.net`、`tzme.net`、HTTP 和 HTTPS 的跳转，确认最终地址与规范链接一致，避免多个域名版本长期并存。
- 访问不存在的产品路径应返回 HTTP 404；后台、预览、站内搜索和多重筛选页应有 `noindex`。
- XML 站点地图只包含已发布内容；产品下架后，新请求不再列出该产品，原详情地址返回 404。
- 在后台调整一次标题或问答，再查看公开页面源码和实际页面，确认保存后同步生效。
- 确认三维场景、产品筛选、设备图片预览、咨询提交、附件上传和管理后台登录在正式域名下正常工作。

测试依据包括服务端 H2 集成测试、真实 HTTP 源码检查以及桌面、手机浏览器检查。本地检查不等同于外网域名已完成发布或已被搜索平台收录。

## 后续内容维护

持续补充真实的制造、检验和交付记录，写清设备名称、应用行业、制造范围、检验关注点、发布机构和发布日期。参数与证书按资料原有口径填写，项目数据保留项目范围说明。

百度等搜索平台的抓取、索引、展现和点击数据，用于判断搜索建设效果；网站现有访问分析和客户咨询用于跟踪实际到站行为。若使用必应站长工具，可参考其 [AI Performance 官方说明](https://blogs.bing.com/webmaster/2026/2/Introducing-AI-Performance-in-Bing-Webmaster-Tools-Public-Preview/) 观察支持场景中的引用页面。清晰标题、真实资料和可见问答有助于准确理解内容，引用和排名仍由平台决定。

服务器直接输出内容的技术依据可参考 [搜索引擎对 JavaScript 内容的处理说明](https://developers.google.cn/search/docs/crawling-indexing/javascript/dynamic-rendering?hl=zh-cn)。本站向普通访客和抓取程序返回同一套公开 HTML。
