06 / HOME

首页

整页十段：Hero → 简介 + 数据 → 服务分类 → 行业 → 流程 → 制造能力 → 案例 → 全球 → 询价 → 页脚。 这是工业 B2B 官网的标准结构，难点不在创意，在于十段调子统一。

07 / PRODUCTS

产品中心

八个分类用编号卡片铺完，下面接三张带参数行的案例卡。 分类卡解决"我们能做什么"，案例卡解决"做过什么"，两段一组就够了。

08 / DETAIL

产品详情

Hero 用产品实拍 + 关键参数，下面接规格与技术要求两栏， 再接一段流程条与三张相关设备卡。右侧交付窗口单独成块，非标设备这一项客户最关心。

09 / ABOUT

关于我们

简介 + 数据带 + 认证 + 三处基地 + 全球分布。 认证区放证书原件扫描，比四个认证名字更有说服力。

10 / INSIGHTS

新闻中心

一条精选 + 一张列表。列表只有日期、标题、类别三列， 没有缩略图也没有摘要 —— 工业客户的阅读方式是扫标题。

11 / CONTACT

联系我们

左信息右表单，表单做成一张深色卡片（十一个字段 + 文件上传）。 表单不做白色卡片 —— 在深藏青上白卡会跳出来，破坏整段调子。

12 / MOBILE

移动端

这一版结构多、分段密，手机上要把每段高度压到六成， 并把所有多列网格降为两列。案例卡的三列参数行刻意保留 —— 那是核心信息。
